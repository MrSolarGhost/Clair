# Collections Screen

Collections are user-curated playlists of games.

They are intentionally lightweight and flexible.

Users can:
- Create and delete collections
- Add or remove games
- Add custom artwork/images to collections
- Browse collections like mini-libraries
- Use a collection as a Home shortcut
- Use a collection as the source for Tonight's Pick

Collections exist to support intention, not hoarding.

## Collection Artwork

Users can set custom artwork for each collection:
- Can be uploaded from local files
- Displayed as the collection's cover/thumbnail
- Used in the directory view and detail pages
- Helps visually organize and personalize collections
